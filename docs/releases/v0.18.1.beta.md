## Added
- Added migration-source validation for older item and Space data before Room migration can be declared complete.
- Added regression coverage for invalid legacy migration sources.

## Changed
- Legacy item/Space JSON is decoded strictly before Dayline removes the old preference copy.
- Valid rows can still seed an empty Room table, but malformed legacy source keeps the migration incomplete so the original data remains available for recovery.

## Fixed
- Fixed a data-loss edge case where malformed legacy records could be skipped and then the original JSON deleted after migration.
- Beta identity aligned to 0.18.1.beta / versionCode 1801.
