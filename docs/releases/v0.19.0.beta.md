## Added
- Added a clearly visible Quick Add action with local time-range, recurrence, reminder and daypart shorthand.
- Added independent top-edge timeline resizing, a persistent short Undo history, direct widget Quick Add/task actions and three-way Calendar sync conflict detection.
- Added This event / This and following / All events choices across recurring saves, moves, resizes and deletions.

## Changed
- Timed events now use shared duration rules so moving a block preserves its exact length.
- Today gives longer blocks more visual space and labels EVENT, TASK, FOCUS and OVERLAP more clearly.
- Settings is simpler, Calendar diagnostics are directly accessible, and Glyph idle motion uses a smaller cleaner expression set with optional brief app states.

## Fixed
- Fixed Quick Add being difficult to discover behind an unlabeled plus button.
- Fixed inconsistent recurrence behavior between form edits, timeline gestures, Quick Move and deletion.
- Fixed Calendar reconciliation overwriting a newer local change when both Dayline and the provider diverged from the last shared state.
