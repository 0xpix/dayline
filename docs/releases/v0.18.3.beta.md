## Added
- Added a lightweight local recovery journal for queued Room item and Space snapshots.

## Changed
- Non-blocking Room writes remain ordered, while the latest queued snapshot is kept outside Room until disk persistence succeeds.
- Pending journal data is replayed safely on the next launch after process death or a Room write failure.

## Fixed
- Closed the durability gap between an immediate UI update and its asynchronous Room disk write.
- Beta identity aligned to 0.18.3.beta / versionCode 1803.
