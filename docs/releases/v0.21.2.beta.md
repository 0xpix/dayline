## Added
- Added a compact Today's meals summary to the Today page.
- Breakfast shows from 06:00–09:00, Lunch from 09:00–13:00, Snacks from 15:00–17:00 and Dinner from 18:00–21:00.
- The current meal is highlighted and past meals fade automatically.
- Tapping the summary opens Plans.

## Changed
- Today only shows meal names, not ingredients, to keep the page clean.
- The summary uses the weekly Plan automatically, so recurring Monday foods appear every Monday.

## Fixed
- Added tests for meal windows and weekday-specific summaries.
- Beta identity aligned to 0.21.2.beta / versionCode 2102.
