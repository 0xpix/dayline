## Added
• Upcoming now has Today, Tomorrow, 7-day and All windows plus a Focus filter.
• Android Calendar changes now flow back into mapped Dayline events, including title, time, recurrence and calendar moves.
• Reminder schedules rebuild after reboot, app update, date, clock or timezone changes.

## Changed
• Today has cleaner spacing, a quieter current-time marker and clearer drag/resize feedback.
• Recurring edits default to This occurrence, with clearer This + following and Entire series choices.
• Focus Glyph time check-ins now show large minutes on top and seconds underneath for better readability.

## Fixed
• Dragging the bottom event handle now changes the end time instead of moving the event start time.
• Reminder alarms now fall back safely if exact-alarm permission changes, and stale reminder notifications are cleared.
• Navigation selection keeps fixed geometry so rows and indicators no longer jump when selected.
• Glyph keeps the v0.14.9 reconnect, watchdog and heartbeat reliability fixes; no new eye expressions were added.
