## Added
- Added a save-time recurring edit prompt with Only this event and Every event.
- Added explicit tracking of the actual item produced by a recurring edit.

## Changed
- Recurring edit scope is no longer a permanent section in the form; Dayline asks only when you save.
- Whole-series edits update the existing master in place, while single-occurrence edits detach only that occurrence.

## Fixed
- Fixed single-occurrence edits falsely conflicting with their own detached replacement.
- Fixed recurring edits looking like duplicate events instead of a scoped edit.
- Beta identity aligned to 0.18.10.beta / versionCode 1810.
