## Added
• Added a conservative Glyph recovery watchdog that waits for Nothing's service to recover naturally before rebuilding the SDK binding.

## Changed
• Glyph SDK callbacks are now serialized onto the main looper to avoid binder-thread races with animation rendering.
• Recovery now uses a clean unInit → init cycle only after a real sustained disconnect, with backoff instead of rapid reconnect attempts.
• Redundant unchanged frames are suppressed inside the hardware bridge, so the old 4-second heartbeat no longer reaches the Matrix hardware.

## Fixed
• Fixed a regression where the v0.14.9 reconnect/heartbeat strategy could make eye animations and Focus timer frames freeze more often and for longer.
• Fixed reconnect churn that could repeatedly reinitialize Nothing's proxy service while it was already trying to reconnect.
• Beta identity is aligned to 0.15.3.beta / versionCode 1503.
