Dayline Privacy Policy

Effective 6 September 2026

Dayline is an open-source Android calendar and planner designed to work primarily on your device.

Data Dayline stores

Dayline stores events, tasks, Spaces, templates, preferences, focus-session state, widget preferences, and completion state locally on your device.

Android Calendar access

Calendar access is optional. If enabled, Dayline requests calendar read/write access so it can display calendars exposed by Android's Calendar Provider and create or update events in a writable calendar you choose. The calendar provider or account you select may independently sync that calendar under its own settings and privacy policy. Dayline does not operate a separate calendar-sync server.

Notifications

Dayline can schedule reminders, ongoing event/focus notifications, and exact alarms when you enable those features. Notification data is generated on-device.

Backups and exports

Backup, restore, ICS import, and ICS export happen only when you explicitly choose a file or location through Android's system file picker. Dayline does not automatically upload backups. Android automatic app-data backup is disabled; backup and restore are explicit Dayline actions.

Analytics, advertising, accounts, and sale of data

Dayline does not include a Dayline account system, advertising SDK, analytics SDK, or Dayline-operated cloud service. Dayline does not sell personal data.

Permissions and control

Dayline may request calendar, notification, exact-alarm, and boot-completed permissions when required by enabled features. Optional permissions can be denied or revoked in Android settings. Turning off Android Calendar sync in Dayline hides the external calendar overlay; it does not delete events owned by another calendar provider.

Retention and deletion

Dayline's local data remains on the device until you delete it, restore another Dayline backup, clear app storage, or uninstall the app. Calendar events written into another Android calendar are retained according to that calendar provider's settings.

Open source and contact

Dayline's source code is available at github.com/0xpix/dayline. Privacy questions can be submitted through the repository's issue or discussion system, or through the developer contact shown on the Google Play listing.

Changes

If Dayline's data practices change, this policy will be updated before a release that introduces those changes.

GitHub beta updates

The separate Dayline β build can contact GitHub when Settings checks for a beta update. It requests public release metadata and, only when you choose Download, downloads the selected APK from GitHub's release infrastructure. Dayline does not send your events, tasks, calendar contents or Dayline settings to GitHub. GitHub and its delivery infrastructure may receive ordinary network information such as your IP address and request metadata under GitHub's own privacy terms. The stable Google Play build does not include Dayline's GitHub self-update permissions.
