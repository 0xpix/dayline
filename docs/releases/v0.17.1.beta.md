## Added
- Added a beta-version bump helper and a CI guard that fails when functional changes land without a newer beta version.
- Added updater/version regression tests.

## Changed
- Static release validation now derives the active beta version from Gradle and checks README, CHANGELOG and updater release-note alignment.
- Backup/restore now uses schema version 2 and excludes transient updater, sync-health and widget-instance cache state.
- The beta updater now compares the downloaded APK signing certificate with the installed Dayline beta before opening Android's installer.

## Fixed
- Restore rejects unsupported future backup schemas before replacing local data while keeping version-1 backups compatible.
- Prevented stale release metadata from silently drifting away from the embedded beta version.
