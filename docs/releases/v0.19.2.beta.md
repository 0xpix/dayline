- Added dynamic matching of dot tokens to existing Dayline Spaces.
- Added Space information to the live UNDERSTOOD preview.

- Plain titles remain plain unless dot shorthand is actually present.

- Fixed `.5min` not setting a five-minute reminder.
- Fixed matching Space names such as `.personal` remaining inside the saved title.
- Fixed compact shorthand punctuation remaining attached to the event name.
