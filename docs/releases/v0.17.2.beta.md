## Added
- Added clear accessibility roles and spoken state to compact Settings controls.

## Changed
- Toggle rows are now one coherent switch target, so tapping either the label or switch changes the same setting.
- Calendar visibility announces the calendar name plus Shown/Hidden state instead of exposing only a filled/empty dot.
- Compact Settings actions expose button semantics while keeping the same minimal visual design.

## Fixed
- Fixed Settings controls that were visually tappable but did not communicate their control type clearly to accessibility services.
- Beta identity aligned to 0.17.2.beta / versionCode 1702.
