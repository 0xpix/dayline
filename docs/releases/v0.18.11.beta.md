## Added
- Added an Only this event / Every event prompt after recurring timeline move and resize gestures.
- Added shared gesture-scope handling that preserves the recurrence anchor for whole-series time changes.

## Changed
- Dragging a recurring event no longer writes a single-occurrence edit immediately; Dayline waits for the scope choice.

## Fixed
- Fixed drag-to-change start time being hardcoded to the selected occurrence.
- Fixed drag-to-change end time being hardcoded to the selected occurrence.
- Fixed recurring drag edits appearing as duplicate/overlapping events instead of scoped edits.
- Beta identity aligned to 0.18.11.beta / versionCode 1811.
