## Added
- Added safer backup restore previews with event, task and Space counts before local data is replaced.
- Added live APK download progress to the in-app beta updater.
- Added updater/version, Glyph Matrix geometry, recurrence-edit and beta-version-tool regression tests.

## Changed
- Backup schema version 2 excludes transient updater, sync-health and widget-instance cache state.
- Backup restore validates nested event/task and Space payloads before clearing current data.
- Saved events/tasks, Spaces, templates and calendar rules isolate malformed records instead of discarding the whole collection.
- Item saves persist to disk asynchronously to avoid blocking timeline interactions.
- Downloaded beta APKs are checked for package, versionCode, size, SHA-256 and signing-certificate identity before Android's installer opens.
- Download progress updates are throttled to meaningful changes.
- Settings actions use larger touch targets, and the Glyph preview now exposes a concise accessibility description.

## Fixed
- Cached update cards now use the same versionCode-aware installability rule as live GitHub checks.
- Granting Android's install-apps permission resumes the verified update automatically when you return to Dayline.
- Unsupported or malformed backups are rejected before replacing local state while version-1 backups remain compatible.
- Fixed multi-line Gradle matching in the beta version helper and guarded it with CI regression tests.
- Prevented stale release metadata from drifting away from the embedded beta version.
