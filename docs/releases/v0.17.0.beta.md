## Added
- Added tappable free-time blocks on Today with quick Event, Task and Focus actions, plus a dedicated All Day strip.
- Added task scheduling windows, richer Quick Move/conflict actions, week/weekday/free-time search commands and expanded local beta diagnostics.
- Added recurrence/planning regression tests and local Glyph transport counters for real-device troubleshooting.

## Changed
- Today now snaps move/resize gestures every 5 minutes, auto-scrolls while dragging, opens near the useful part of the day and fades past blocks more quietly.
- Month/Day Preview, Fit into my day, widgets and Android Calendar synchronization now handle daily flow and time changes more reliably.
- Timed Calendar events preserve their provider timezone through Dayline edits, and Quick Add retains v0.17 task scheduling metadata when editing an item.
- The beta updater keeps Added / Changed / Fixed sections intact, shows concise publish-date/APK-size metadata and verifies the downloaded size before installation.

## Fixed
- Fixed release-note headings being stripped before the in-app updater could render them as separate sections.
- Fixed monthly recurrence on the 29th/30th/31st, all-day events consuming timed free space, and Calendar timezone round-tripping for provider events.
- Fixed widget refresh after reboot, app replacement, manual clock changes, timezone changes and date changes.
