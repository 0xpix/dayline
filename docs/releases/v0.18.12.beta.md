## Added
- Added robust RFC 2445 calendar duration parsing with regression coverage for multi-hour events.
- Added preservation of the existing Dayline duration when Android Calendar returns no trustworthy end time.

## Changed
- Calendar sync no longer substitutes one hour for missing or malformed provider duration data.
- If a provider-side edit changes the start time but temporarily omits the end, Dayline shifts the saved duration with the new start.

## Fixed
- Fixed events such as 06:00–09:30 randomly becoming 06:00–07:00 after synchronization.
- Fixed valid local event end times being overwritten by a synthetic one-hour fallback.
- Beta identity aligned to 0.18.12.beta / versionCode 1812.
