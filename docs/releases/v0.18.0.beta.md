## Added
- Added fully local Quick Add shorthand: try `gym tomorrow 7:30 1h`, `dentist Friday 14:00`, `task report 45m due Monday` or `focus 50m at 18:00`.
- Added a Room-backed local database for events, tasks and Spaces with automatic one-time migration from older Dayline beta data.
- Added regression coverage for Quick Add parsing, hidden item metadata and Room model round trips.

## Changed
- Events/tasks and Spaces now use Room as their local source of truth while normal preferences stay lightweight.
- Existing event/task and Space order is preserved through migration.
- Backup/export remains compatible with existing Dayline backup files even though live storage moved to Room.
- Quick Add only applies shorthand when it finds an explicit date/time/duration/task/focus/due directive; ordinary titles are left alone.

## Fixed
- Converting a Calendar-backed event into a task no longer leaves stale Android Calendar IDs, read-only state or timezone metadata attached.
- Timed-to-all-day event edits retain valid Calendar mapping while removing timed-only metadata.
- Restore rolls back Room data if restoring the rest of the settings cannot be completed.
- Beta identity aligned to 0.18.0.beta / versionCode 1800.
