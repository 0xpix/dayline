## Added
- Added a lightweight recovery journal for the latest queued item and Space Room snapshots.
- Added startup replay for pending Room journals plus a Room write-health row in hidden beta diagnostics.

## Changed
- Normal Room writes stay non-blocking and ordered, while the newest pending snapshot remains recoverable until Room confirms persistence.
- An older write completion cannot clear a newer journal entry.
- Pending Room journals and write-error state are excluded from normal Dayline backups.

## Fixed
- Closed the crash/failure window between an immediate UI update and its asynchronous Room disk write.
- Failed queued writes now keep their recovery journal for replay on the next initialization instead of disappearing silently.
- Beta identity aligned to 0.18.3.beta / versionCode 1803.
