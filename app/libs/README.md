# Nothing Glyph Matrix SDK

Dayline does **not** commit or redistribute Nothing's closed-source Glyph Matrix AAR.

For local beta builds, download the official `glyph-matrix-sdk-2.0.aar` from:

`Nothing-Developer-Programme/GlyphMatrix-Developer-Kit`

and place it in this directory as:

`app/libs/glyph-matrix-sdk-2.0.aar`

GitHub Actions fetches the same official AAR automatically for GitHub beta builds.
The Play flavor deliberately does not bundle the SDK until commercial licensing is resolved with Nothing.
