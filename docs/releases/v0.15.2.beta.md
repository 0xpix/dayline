## Added
• Upcoming now has Today, Tomorrow, 7-day and All windows plus a Focus filter.
• Android Calendar changes now flow back into mapped Dayline events, including title, time, recurrence and calendar moves.
• Reminder schedules rebuild after reboot, app update, date, clock or timezone changes.

## Changed
• Today has cleaner spacing, a quieter current-time marker and clearer drag/resize feedback.
• Recurring edits default to This occurrence, with clearer This + following and Entire series choices.
• Focus Glyph time check-ins show large minutes on top and seconds underneath for better readability.

## Fixed
• Dragging the bottom event handle changes the end time instead of moving the event start time.
• Reminder alarms fall back safely if exact-alarm permission changes, and stale reminder notifications are cleared.
• Navigation selection keeps fixed geometry so rows and indicators do not jump when selected.
• Glyph retains reconnect, watchdog and heartbeat recovery so timer/eye frames recover after Matrix service interruptions.
• Release identity is aligned to 0.15.2.beta / versionCode 1502 so the Git tag and APK pass the release verification step.
