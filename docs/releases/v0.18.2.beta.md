## Added
- Added ordered background Room persistence for normal event/task and Space changes.
- Added explicit synchronous Room write paths reserved for backup restore and rollback.

## Changed
- Normal UI mutations update Dayline immediately and queue disk persistence on the single Room executor instead of waiting for disk I/O.
- Restore still waits for Room writes before committing settings, so rollback remains deterministic.

## Fixed
- Fixed the v0.18 Room storage layer reintroducing blocking disk waits into drag, resize, Quick Add, task completion and other normal UI mutation paths.
- Beta identity aligned to 0.18.2.beta / versionCode 1802.
